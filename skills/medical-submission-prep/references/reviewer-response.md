## Reviewer Response Mode

When reviewer comments or editor letters are present:

- read the existing decision letter for the decision, deadline, required files
  and intended reviewer visibility; missing Major/Minor labels do not prevent
  an otherwise well-scoped comment audit or already-authorized text repair;
- extract editor instructions and reviewer comments into stable IDs;
- preserve each comment before responding;
- classify comments by action: text repair, analysis repair, figure/table
  repair, citation repair, disagreement, impossible request, or author input;
- map every claimed change to manuscript location, figure/table/supplement
  ref, or an explicit placeholder;
- mark missing author information as `AUTHOR_INPUT_NEEDED`;
- route statistical, literature, writing, table, and figure repairs to sibling
  skills instead of pretending the response letter itself fixes the paper.

Record the action state as planned, done or partly done with the evidence for
that state. A planned analysis or unperformed edit cannot be described as
completed. Separate a justified disagreement from an unsupported assertion,
and preserve unresolved author inputs without inventing them.

For changes that affect the package, keep the response letter, clean manuscript,
marked manuscript and applicable supplements consistent. After the relevant
edit, recheck quoted text and page/line locations against the actual export;
unchanged comments and evidence can be reused. Put the detailed answer in the
response, and make the manuscript change as concise as the scientific argument
allows. Red text is one journal-specific option, not a universal requirement;
retain track changes or other accepted markup when that is the package format.
Use separate reviewer letters only when the journal's actual visibility rules
or instructions require them.

This adapts the reviewed Nature response patterns recorded in
[upstream provenance](upstream-provenance.md). It creates response evidence and
repair candidates, not journal acceptance or a MAS owner receipt.
